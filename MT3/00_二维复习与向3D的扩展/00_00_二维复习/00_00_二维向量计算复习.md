# 向量复习

`向量` 可以理解为同时拥有 `direction（方向）` 和 `length（长度）` 的量。

---

# 1. 常用计算用名称

## 1.1 常用向量

| 向量种类 | 常用变量名 | 用处 |
|---|---|---|
| 位置向量 | `position` | 物体的位置 |
| 基准位置向量 | `basePos` | 计算起点 |
| 目标位置向量 | `targetPos` | 移动或追踪目标 |
| 指向目标的向量 | `toTarget` | 由 `targetPos - position` 得到，用于方向、距离、范围判定 |
| 面向向量 | `forward` | 视野、面向、攻击方向 |
| 方向向量 | `direction` | 表示移动方向，通常会处理成单位向量 |
| 单位向量 | `unitDirection` | 长度为 `1` 的方向，用于稳定移动速度 |
| 速度向量 | `velocity` | 由 `unitDirection * speed` 得到，表示移动方向和速度大小 |
| 移动量向量 | `move` | 由 `velocity * deltaTime` 得到，最终加到 `position` 上 |

补充：实际代码中，`direction` 经常默认表示已经正規化后的单位方向。  
如果想特别强调“长度为 `1`”，也可以写成 `unitDirection`。

---

## 1.2 常用标量

| 标量种类 | 常用变量名 | 用处 |
|---|---|---|
| 长度 | `length` | 向量长度、正規化 |
| 速度大小 | `speed` | 设定的移动速度 |
| 时间差 | `deltaTime` | 帧率补正 |
| 距离 | `distance` | 距离判定 |
| 判定范围 | `range` | 视野、攻击、搜索 |
| 半径 | `radius` | 圆形碰撞、范围判定 |

# 2. 各种基础计算

- `v + v` / `v - v`
- `v * k` / `v / k`
- `|v|`
- `normalize(v)`
- `a・b`
- `a × b`

---

## 2.1 v + v / v - v

- `a + b = (ax + bx, ay + by)`

  ```cpp
  Vector2 Add(Vector2 a, Vector2 b) {
      Vector2 result;

      result.x = a.x + b.x;
      result.y = a.y + b.y;

      return result;
  }

  Vector2 newPos = Add(position, move);
  ```

- `a - b = (ax - bx, ay - by)`

  ```cpp
  Vector2 Subtract(Vector2 a, Vector2 b) {
      Vector2 result;

      result.x = a.x - b.x;
      result.y = a.y - b.y;

      return result;
  }

  Vector2 toTarget = Subtract(targetPos, position);
  ```

直接用途：

- `position + move`：更新位置
- `targetPos - position`：求出从自己指向目标的向量

减法的结果可以继续用于：

- 计算方向
- 计算距离
- 追踪移动
- 范围判定

---

## 2.2 v * k / v / k

- `a * k = (ax * k, ay * k)`

  ```cpp
  Vector2 Multiply(Vector2 v, float k) {
      Vector2 result;

      result.x = v.x * k;
      result.y = v.y * k;

      return result;
  }

  Vector2 velocity = Multiply(direction, speed);
  Vector2 move = Multiply(velocity, deltaTime);
  ```

- `a / k = (ax / k, ay / k)`

  ```cpp
  Vector2 Divide(Vector2 v, float k) {
      Vector2 result;

      result.x = v.x / k;
      result.y = v.y / k;

      return result;
  }

  Vector2 direction = Divide(toTarget, length);
  ```

直接用途：

- `direction * speed`：根据方向和速度大小，得到速度向量
- `velocity * deltaTime`：根据速度和时间，得到本帧移动量
- `toTarget / length`：把指向目标的向量变成单位方向

---

## 2.3 |v|

`|v|` 表示向量长度。

公式：

`|v| = √(x² + y²)`

```cpp
float Length(Vector2 v) {
    float result;

    result = sqrtf(v.x * v.x + v.y * v.y);

    return result;
}
```

常见用途：

- 求两个物体之间的距离
- 判断是否进入范围
- 正規化前先求向量长度

---

## 2.4 正規化

`normalize(v) = v / length(v)`

```cpp
Vector2 Normalize(Vector2 v) {
    Vector2 result;

    float length = sqrtf(v.x * v.x + v.y * v.y);

    if (length != 0.0f) {
        result.x = v.x / length;
        result.y = v.y / length;
    } else {
        result.x = 0.0f;
        result.y = 0.0f;
    }

    return result;
}
```

`正規化` 是指保持方向不变，把向量长度变成 `1`。  
正規化后的向量叫做 `単位ベクトル`，也就是单位向量。

### 为什么要正規化

如果不正規化，直接拿一个很长的向量去乘 `speed`，移动速度会受到原本向量长度影响。

例如：

`(1, 0)` 和 `(10, 0)` 都是向右的向量。

但是：

- `(1, 0)` 的长度是 `1`
- `(10, 0)` 的长度是 `10`

如果 `speed = 5`：

`(1, 0) * 5 = (5, 0)`

`(10, 0) * 5 = (50, 0)`

方向虽然一样，但第二个移动得更快。

所以移动前通常要先正規化，只保留方向，把长度统一成 `1`。  
这样速度才由 `speed` 控制。

### 为什么不能除以 0

正規化时需要计算：

`v / length`

如果 `length` 是 `0`，就会变成除以 `0`。  
程序中除以 `0` 会导致错误结果，所以需要先判断：

```cpp
if (length != 0.0f) {
    // 正規化する
}
```

## 2.5 整体移动函数

多个基础运算可以组合成一个移动函数。  
这个函数用于让物体从当前位置 `objectPos` 朝目标位置 `targetPos` 移动。

```cpp
Vector2 MoveToTarget(Vector2 objectPos, Vector2 targetPos, float speed, float deltaTime) {
    Vector2 toTarget = Subtract(targetPos, objectPos);

    Vector2 direction = Normalize(toTarget);

    Vector2 velocity = Multiply(direction, speed);

    Vector2 move = Multiply(velocity, deltaTime);

    Vector2 newPos = Add(objectPos, move);

    return newPos;
}
```

使用例：

```cpp
objectPos = MoveToTarget(objectPos, targetPos, speed, deltaTime);
```

### 分级理解

- `toTarget = targetPos - objectPos`
  - 求出从当前物体指向目标的向量

- `direction = Normalize(toTarget)`
  - 把 `toTarget` 变成长度为 `1` 的单位方向

- `velocity = direction * speed`
  - 根据方向和速度大小，得到速度向量

- `move = velocity * deltaTime`
  - 根据速度和一帧时间，得到本帧移动量

- `newPos = objectPos + move`
  - 把本帧移动量加到当前位置上，得到新的位置

这个函数适合用于“朝目标点移动”的情况，例如敌人追玩家、物体飞向目标位置等。
```

### 2.5.1 分级理解

- `targetPos - objectPos`
  - 使用运算：向量减法
  - 得到结果：从当前物体指向目标的向量
  - 含义：目标在当前物体看来在哪个方向、离多远

- `Normalize(targetPos - objectPos)`
  - 使用运算：正規化
  - 得到结果：长度为 `1` 的单位方向
  - 含义：只保留方向，不保留距离

- `direction * speed`
  - 使用运算：向量 × 标量
  - 得到结果：速度向量 `velocity`
  - 含义：每秒往这个方向移动多少

- `velocity * deltaTime`
  - 使用运算：向量 × 标量
  - 得到结果：本帧移动量 `move`
  - 含义：这一帧实际移动多少

- `objectPos + move`
  - 使用运算：向量加法
  - 得到结果：新的位置
  - 含义：把本帧移动量加到当前位置上

## 2.6 两种移动情况

移动不一定都要计算 `toTarget`。

### 情况一：已经知道移动方向

例如玩家按键移动、子弹向右飞、角色朝当前面向方向前进。  
这种情况下可以直接使用 `direction` 或 `forward`，不需要计算 `targetPos - position`。

```cpp
direction = {1.0f, 0.0f};
velocity = direction * speed;
move = velocity * deltaTime;
position = position + move;
```

### 情况二：朝目标点移动

例如敌人追玩家、物体飞向目标位置。  
这种情况下只有当前位置和目标位置，所以需要先计算：

```cpp
toTarget = targetPos - position;
```

然后再正規化成移动方向：

```cpp
direction = Normalize(toTarget);
```

一句话总结：

`已经有方向` → 直接用 `direction`。  
`只有目标点` → 先算 `toTarget = targetPos - position`。

## 10. 距离公式：由向量减法派生

距离判断不是直接用两个坐标，而是先求差向量，再求长度。

### 10.1 两点差向量

- 使用运算：向量减法
- 公式：`diff = posA - posB`
- 结果类型：向量
- 含义：得到 A 相对于 B 的位置方向

例如：

`posA = (10, 5)`

`posB = (4, 1)`

那么：

`diff = posA - posB = (6, 4)`

这个 `(6, 4)` 表示：A 相对于 B，在右边 `6`、下边 `4`。

### 10.2 两点距离

- 前提公式：`diff = posA - posB`
- 使用运算：向量减法 + 长度
- 公式：`distance = length(posA - posB)`
- 展开公式：`distance = √((posA.x - posB.x)² + (posA.y - posB.y)²)`
- 结果类型：数值
- 含义：得到 A 和 B 之间实际相隔多远

例如：

`diff = (6, 4)`

那么：

`distance = length(diff)`

`distance = √(6² + 4²)`

`distance = √52`

`distance ≈ 7.21`

### 10.3 区别总结

| 写法 | 结果类型 | 含义 |
|---|---|---|
| `posA - posB` | 向量 | A 相对于 B 的位置方向，包含方向和长度信息 |
| `length(posA - posB)` | 数值 | A 和 B 之间的实际距离，只保留长度信息 |

简单记忆：

`减法得到方向向量，length 得到距离数值。`

### 10.4 由距离公式派生出的常用判断

距离公式本身只是得到两个点之间的距离：

`distance = length(posA - posB)`

有了这个距离以后，才可以继续派生出范围判断、圆形碰撞，以及它们的优化版。

- [11. 距离公式的应用：范围判断](#11-距离公式的应用范围判断)
  - 前提公式：`distance = length(targetPos - basePos)`
  - 派生公式：`distance <= range`
  - 合并写法：`length(targetPos - basePos) <= range`
  - 含义：判断目标是否进入以基准点为中心的范围。

- [12. 距离公式的应用：圆形碰撞](#12-距离公式的应用圆形碰撞)
  - 前提公式：`distance = length(posA - posB)`
  - 派生公式：`distance <= radiusA + radiusB`
  - 合并写法：`length(posA - posB) <= radiusA + radiusB`
  - 含义：判断两个圆是否接触或重叠。

- [15. 距离平方：由内积派生](#15-距离平方由内积派生)
  - 前提公式：`diff = posA - posB`
  - 派生公式：`distanceSq = dot(diff, diff)`
  - 含义：不用 `sqrt`，直接得到两点距离的平方。

- [16. 距离平方的应用：范围判断优化版](#16-距离平方的应用范围判断优化版)
  - 前提公式：`distanceSq = dot(diff, diff)`
  - 派生公式：`distanceSq <= range * range`
  - 含义：不用开平方判断目标是否进入范围。

- [17. 距离平方的应用：圆形碰撞优化版](#17-距离平方的应用圆形碰撞优化版)
  - 前提公式：`distanceSq = dot(diff, diff)`
  - 派生公式：`distanceSq <= (radiusA + radiusB) * (radiusA + radiusB)`
  - 含义：不用开平方判断两个圆是否碰撞。

简单关系：

`向量减法 → 差向量 → length 求距离 → 范围判断 / 圆形碰撞`

优化关系：

`向量减法 → 差向量 → dot(diff, diff) 求距离平方 → 范围判断优化 / 圆形碰撞优化`

## 11. 距离公式的应用：范围判断

### 11.1 范围判断公式

- 前提公式：`distance = length(targetPos - basePos)`
- 使用运算：向量减法 + 长度 + 比较
- 公式：`length(targetPos - basePos) <= range`
- 结果类型：bool
- 含义：判断目标是否进入以基准点为中心的范围

### 11.2 分级理解

- `targetPos - basePos`
  - 使用运算：向量减法
  - 得到目标相对于基准点的差向量

- `length(targetPos - basePos)`
  - 使用运算：长度
  - 得到目标和基准点之间的距离

- `<= range`
  - 使用运算：比较
  - 判断距离是否小于等于范围半径

### 11.3 范围判断的常见用途

范围判断公式是：

`length(targetPos - basePos) <= range`

它的本质是：判断目标是否进入以 `basePos` 为中心、半径为 `range` 的圆形范围。

- 攻击范围判断
  - 使用公式：`length(playerPos - enemyPos) <= attackRange`
  - 含义：判断玩家是否进入敌人的攻击范围。
  - 相关基础：[10. 距离公式：由向量减法派生](#10-距离公式由向量减法派生)

- 拾取范围判断
  - 使用公式：`length(itemPos - playerPos) <= pickupRange`
  - 含义：判断道具是否进入玩家的拾取范围。
  - 相关基础：[10. 距离公式：由向量减法派生](#10-距离公式由向量减法派生)

- 视野距离判断
  - 使用公式：`length(targetPos - observerPos) <= viewRange`
  - 含义：先判断目标是否在观察者的视野距离内。
  - 进一步的方向和角度判断看：[13.4 判断目标是否在前方](#134-判断目标是否在前方) 和 [13.5 视野角度判断](#135-视野角度判断)。

- 触发区域判断
  - 使用公式：`length(playerPos - triggerPos) <= triggerRange`
  - 含义：判断玩家是否进入某个触发区域，例如开门、对话、机关启动等。
  - 相关基础：[10. 距离公式：由向量减法派生](#10-距离公式由向量减法派生)

- 优化版范围判断
  - 普通范围判断：`length(targetPos - basePos) <= range`
  - 优化版范围判断：`dot(diff, diff) <= range * range`
  - 详细说明看：[16. 距离平方的应用：范围判断优化版](#16-距离平方的应用范围判断优化版)。

简单关系：

`距离公式 → 范围判断 → 攻击范围 / 拾取范围 / 视野距离 / 触发区域`

如果只需要判断“有没有进入范围”，不需要真实距离数值，程序中更推荐使用距离平方优化版。

## 12. 距离公式的应用：圆形碰撞

### 12.1 圆形碰撞公式

- 前提公式：`distance = length(posA - posB)`
- 使用运算：向量减法 + 长度 + 比较
- 公式：`length(posA - posB) <= radiusA + radiusB`
- 结果类型：bool
- 含义：判断两个圆是否接触或重叠

### 12.2 分级理解

- `posA - posB`
  - 使用运算：向量减法
  - 得到两个圆心之间的差向量

- `length(posA - posB)`
  - 使用运算：长度
  - 得到两个圆心之间的距离

- `radiusA + radiusB`
  - 使用运算：数值加法
  - 得到两个圆半径之和

- `distance <= radiusA + radiusB`
  - 使用运算：比较
  - 如果圆心距离小于等于半径和，说明两个圆碰撞

### 12.3 范围判断和圆形碰撞的关系

- 范围判断
  - `length(targetPos - basePos) <= range`xxx
  - 可以理解为“点进入圆形范围”

- 圆形碰撞
  - `length(posA - posB) <= radiusA + radiusB`
  - 可以理解为“圆和圆之间的距离判断”

所以：

`范围判断和圆形碰撞本质上都是距离比较。`

区别是：

| 类型 | 比较对象 |
|---|---|
| 范围判断 | 距离 `<= range` |
| 圆形碰撞 | 距离 `<= radiusA + radiusB` |

## 13. 内積 / 点积

### 13.1 含义

`内積` 也叫 `点积`。

程序里常写作：

`dot(a, b)`

数学符号常写成：

`a・b`

它的结果不是向量，而是一个普通数值。

### 13.2 公式

如果：

`a = (ax, ay)`

`b = (bx, by)`

那么：

`dot(a, b) = ax * bx + ay * by`

### 13.3 用法一：判断方向关系

当内积用于两个不同方向向量时，例如：

`dot(a, b)`

它常用于判断两个方向之间的关系。

| 内积结果 | 方向关系 |
|---|---|
| `dot(a, b) > 0` | 两个方向大致同向 |
| `dot(a, b) == 0` | 两个方向垂直 |
| `dot(a, b) < 0` | 两个方向大致相反 |

更准确的公式：

`dot(a, b) = ||a||||b||cosθ`

这里的 `θ` 是两个向量之间的夹角。

如果两个向量都已经正规化，也就是长度都是 `1`，那么公式会变成：

`dot(a, b) = cosθ`

这时候内积结果就可以直接用来判断角度关系。

### 13.4 判断目标是否在前方

- 前提公式：`toTarget = normalize(targetPos - observerPos)`
- 使用运算：向量减法 + 正规化 + 内积
- 公式：`dot(forward, toTarget) > 0`
- 结果类型：bool
- 含义：判断目标是否大致在观察者前方

代码思路：

```cpp
Vector2 toTarget = Subtract(targetPos, observerPos);

Vector2 directionToTarget = Normalize(toTarget);

float dotValue = Dot(forward, directionToTarget);

if (dotValue > 0.0f) {
    // 目标大致在前方
}
```

### 13.5 视野角度判断

- 前提公式：`toTarget = normalize(targetPos - observerPos)`
- 使用运算：向量减法 + 正规化 + 内积 + cos + 比较
- 公式：`dot(forward, toTarget) > cos(halfFov)`
- 结果类型：bool
- 含义：判断目标是否在观察者视野角度内

例如：

`halfFov` 是半视野角。

`dot(forward, toTarget)` 越接近 `1`，说明目标越接近正前方。

### 13.6 投影长度

- 使用运算：内积
- 公式：`projectLength = dot(v, unitDir)`
- 结果类型：数值
- 含义：计算向量 `v` 在单位方向 `unitDir` 上的长度

## 14. 内积的另一个用法：求长度平方

内积不只可以判断方向。

当一个向量和自己做内积时：

`dot(v, v)`

它表示：

`dot(v, v) = v.x * v.x + v.y * v.y`

也就是：

`dot(v, v) = length(v)²`

所以它可以用于 [15. 距离平方：由内积派生](#15-距离平方由内积派生)、[16. 距离平方的应用：范围判断优化版](#16-距离平方的应用范围判断优化版)、[17. 距离平方的应用：圆形碰撞优化版](#17-距离平方的应用圆形碰撞优化版)。

### 14.1 求长度平方

- 使用运算：内积
- 公式：`lengthSq(v) = dot(v, v)`
- 结果类型：数值
- 含义：得到向量长度的平方

例如：

`v = (3, 4)`

那么：

`dot(v, v) = 3 * 3 + 4 * 4 = 25`

而：

`length(v) = 5`

所以：

`dot(v, v) = length(v)²`

## 15. 距离平方：由内积派生

### 15.1 两点距离平方

- 前提公式：`diff = posA - posB`
- 使用运算：向量减法 + 内积
- 公式：

```cpp
diff = posA - posB;
distanceSq = dot(diff, diff);
```

- 结果类型：数值
- 含义：得到两点距离的平方，避免使用 `sqrt`

### 15.2 为什么可以这样写

普通距离公式：

`distance = length(diff)`

也就是：

`distance = √(diff.x² + diff.y²)`

如果只做大小比较，可以不用开平方，直接比较平方：

`distance² <= range²`

而：

`distance² = dot(diff, diff)`

所以可以写成：

`dot(diff, diff) <= range²`

## 16. 距离平方的应用：范围判断优化版

### 16.1 公式

- 前提公式：`distanceSq = dot(diff, diff)`
- 使用运算：向量减法 + 内积 + 比较
- 公式：

```cpp
diff = targetPos - basePos;
distanceSq = dot(diff, diff);

if (distanceSq <= range * range) {
    // 目标进入范围
}
```

- 结果类型：bool
- 含义：不用 `length` 和 `sqrt`，直接用距离平方判断范围

### 16.2 分级理解

- `diff = targetPos - basePos`
  - 向量减法
  - 得到目标相对于基准点的差向量

- `dot(diff, diff)`
  - 内积
  - 得到差向量的长度平方，也就是距离平方

- `range * range`
  - 数值乘法
  - 得到范围半径的平方

- `distanceSq <= range * range`
  - 比较
  - 判断目标是否进入范围

## 17. 距离平方的应用：圆形碰撞优化版

### 17.1 公式

- 前提公式：`distanceSq = dot(diff, diff)`
- 使用运算：向量减法 + 内积 + 比较
- 公式：

```cpp
diff = posA - posB;
distanceSq = dot(diff, diff);
radiusSum = radiusA + radiusB;

if (distanceSq <= radiusSum * radiusSum) {
    // 两个圆碰撞
}
```

- 结果类型：bool
- 含义：不用开平方，也能判断两个圆是否碰撞

### 17.2 分级理解

- `diff = posA - posB`
  - 向量减法
  - 得到两个圆心之间的差向量

- `dot(diff, diff)`
  - 内积
  - 得到两个圆心距离的平方

- `radiusA + radiusB`
  - 数值加法
  - 得到两个圆半径之和

- `radiusSum * radiusSum`
  - 数值乘法
  - 得到半径和的平方

- `distanceSq <= radiusSum * radiusSum`
  - 比较
  - 如果成立，两个圆碰撞

## 18. 外積

### 18.1 含义

`外積` 也是两个向量之间的计算。

在二维中，外积常用来判断左右方向、旋转方向、平行关系、点在边的哪一侧等。

二维外积的结果通常当作一个普通数值来使用。

### 18.2 公式

如果：

`a = (ax, ay)`

`b = (bx, by)`

那么二维外积可以写成：

`cross(a, b) = ax * by - ay * bx`

也就是：

`cross(a, b) = a.x * b.y - a.y * b.x`

### 18.3 例子

`a = (1, 0)`

`b = (0, 1)`

所以：

`cross(a, b) = 1 * 1 - 0 * 0 = 1`

结果大于 `0`，表示 `b` 在 `a` 的某一侧。

具体是左侧还是右侧，要看当前坐标系。

### 18.4 判断目标在左边还是右边

- 前提公式：`toTarget = targetPos - observerPos`
- 使用运算：向量减法 + 外积
- 公式：`cross(forward, toTarget)`
- 结果类型：数值
- 含义：根据外积正负判断目标在观察者的哪一侧

### 18.5 判断旋转方向

- 前提公式：`cross(a, b)`
- 使用运算：外积 + 比较
- 公式：`cross(a, b) > 0 / < 0`
- 结果类型：数值
- 含义：判断从方向 `a` 转向方向 `b` 是顺时针还是逆时针

### 18.6 判断两个方向是否平行

- 前提公式：`cross(a, b)`
- 使用运算：外积 + 比较
- 公式：`cross(a, b) == 0`
- 结果类型：bool
- 含义：外积为 `0` 时，两个方向平行

### 18.7 判断点在边的哪一侧

- 前提公式：`edge = end - start`
- 使用运算：向量减法 + 外积
- 公式：

```cpp
edge = end - start;
toPoint = point - start;
cross(edge, toPoint);
```

- 结果类型：数值
- 含义：判断点在一条边的哪一侧

### 18.8 三角形内部判定

- 前提公式：`cross(edge, point - vertex)`
- 使用运算：外积 + 同号判断
- 公式：

```cpp
cross(edge1, point - vertex1);
cross(edge2, point - vertex2);
cross(edge3, point - vertex3);
```

- 结果类型：bool
- 含义：如果点相对于三条边的外积结果符号一致，通常可以判断点在三角形内部

### 18.9 程序理解

```cpp
float Cross(Vector2 a, Vector2 b) {
    float result;

    result = a.x * b.y - a.y * b.x;

    return result;
}
```

### 18.10 注意点

二维外积结果大于 `0` 或小于 `0` 时，表示两侧不同。

但是到底哪边是左、哪边是右，要看坐标系。

在数学坐标系中，通常 `y` 轴向上。

在屏幕坐标系中，通常 `y` 轴向下。

所以判断左右时，不要只死背正负号，最好结合当前坐标系画图确认。

## 19. 常见计算流程

### 19.1 朝目标移动

目标：让物体朝目标移动。

流程：

- `targetPos - objectPos`
  - 求目标相对于物体的位置向量

- `normalize(targetPos - objectPos)`
  - 得到单位方向

- `direction * speed`
  - 得到速度

- `velocity * deltaTime`
  - 得到本帧移动量

- `objectPos + move`
  - 更新位置

代码思路：

```cpp
Vector2 toTarget = Subtract(targetPos, objectPos);

Vector2 direction = Normalize(toTarget);

Vector2 velocity = Multiply(direction, speed);

Vector2 move = Multiply(velocity, deltaTime);

objectPos = Add(objectPos, move);
```

---

### 19.2 判断距离

目标：判断两个物体之间有多远。

流程：

- `posA - posB`
  - 得到两点差向量

- `length(posA - posB)`
  - 得到两点距离

代码思路：

```cpp
Vector2 diff = Subtract(posA, posB);

float distance = Length(diff);
```

---

### 19.3 判断范围

目标：判断目标是否进入范围。

流程：

- `targetPos - basePos`
  - 得到目标相对于基准点的差向量

- `length(targetPos - basePos)`
  - 得到目标和基准点之间的距离

- `distance <= range`
  - 判断是否进入范围

代码思路：

```cpp
Vector2 diff = Subtract(targetPos, basePos);

float distance = Length(diff);

if (distance <= range) {
    // 目标进入范围
}
```

---

### 19.4 判断圆形碰撞

目标：判断两个圆是否碰撞。

流程：

- `posA - posB`
  - 得到两个圆心之间的差向量

- `length(posA - posB)`
  - 得到两个圆心之间的距离

- `distance <= radiusA + radiusB`
  - 判断是否碰撞

代码思路：

```cpp
Vector2 diff = Subtract(posA, posB);

float distance = Length(diff);

float radiusSum = radiusA + radiusB;

if (distance <= radiusSum) {
    // 两个圆碰撞
}
```

---

### 19.5 判断圆形碰撞优化版

目标：不用开平方判断两个圆是否碰撞。

流程：

- `posA - posB`
  - 得到两个圆心之间的差向量

- `dot(diff, diff)`
  - 得到距离平方

- `(radiusA + radiusB) * (radiusA + radiusB)`
  - 得到半径和平方

- `distanceSq <= radiusSumSq`
  - 判断是否碰撞

代码思路：

```cpp
Vector2 diff = Subtract(posA, posB);

float distanceSq = Dot(diff, diff);

float radiusSum = radiusA + radiusB;

float radiusSumSq = radiusSum * radiusSum;

if (distanceSq <= radiusSumSq) {
    // 两个圆碰撞
}
```

---

### 19.6 判断是否面向目标

目标：判断观察者是否大致看向目标。

流程：

- `targetPos - observerPos`
  - 得到目标相对于观察者的位置向量

- `normalize(targetPos - observerPos)`
  - 得到目标方向

- `dot(forward, toTarget)`
  - 判断观察者前方向和目标方向是否接近

代码思路：

```cpp
Vector2 toTarget = Subtract(targetPos, observerPos);

Vector2 directionToTarget = Normalize(toTarget);

float dotValue = Dot(forward, directionToTarget);

if (dotValue > 0.0f) {
    // 目标大致在观察者前方
}
```

---

### 19.7 判断目标在左边还是右边

目标：判断目标在观察者左边还是右边。

流程：

- `targetPos - observerPos`
  - 得到目标相对于观察者的位置向量

- `cross(forward, toTarget)`
  - 根据外积正负判断左右

代码思路：

```cpp
Vector2 toTarget = Subtract(targetPos, observerPos);

float crossValue = Cross(forward, toTarget);

if (crossValue > 0.0f) {
    // 目标在某一侧
} else if (crossValue < 0.0f) {
    // 目标在另一侧
}
```

注意：具体正数是左还是右，要看当前坐标系。

## 20. 总整理表

| 计算 | 公式 | 结果 | 主要用途 |
|---|---|---|---|
| 向量加法 | `a + b = (ax + bx, ay + by)` | 向量 | 位置更新、移动 |

| 内积 | `dot(a, b) = axbx + ayby` | 数值 | 判断方向关系、夹角 |
| 长度平方 | `dot(a, a)` | 数值 | 距离平方、碰撞优化 |
| 外积 | `cross(a, b) = axby - aybx` | 数值 | 判断左右、旋转方向 |

## 22. 一句话记忆

`向量 + 向量`：常用于位置移动。

`向量 - 向量`：常用于求相对位置和方向。

`向量 × 数值`：常用于控制长度、速度、移动量。

`向量 / 数值`：常用于缩短向量，正规化时会用到。

`length`：表示向量有多长，常用于距离判断。

`正規化`：把向量变成长度为 `1` 的纯方向。

`内積 / 点积`：判断两个方向像不像、夹角大不大；也可以用 `dot(v, v)` 求长度平方。

`外積`：判断左右、旋转方向、点在边的哪一侧。

## 23. 和三维向量的关系

二维向量是：

`v = (x, y)`

三维向量是：

`v = (x, y, z)`

三维向量的大部分计算，就是在二维的基础上多算一个 `z`。

例如二维加法：

`(x1, y1) + (x2, y2) = (x1 + x2, y1 + y2)`

三维加法：

`(x1, y1, z1) + (x2, y2, z2) = (x1 + x2, y1 + y2, z1 + z2)`

二维长度：

`length(v) = √(x² + y²)`

三维长度：

`length(v) = √(x² + y² + z²)`

二维内积：

`dot(a, b) = axbx + ayby`

三维内积：

`dot(a, b) = axbx + ayby + azbz`

所以从二维扩展到三维时，先记住一句话：

`大多数计算只是多处理一个 z。`

但是 `外積` 比较特殊，二维和三维差别较大，三维外积之后需要单独学习。
