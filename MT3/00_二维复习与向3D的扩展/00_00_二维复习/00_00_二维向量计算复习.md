# 二维向量计算复习

`向量` 可以理解为同时拥有 `方向` 和 `长度` 的量。

二维向量通常写成：

`v = (x, y)`

其中：

| 成分 | 含义 |
|---|---|
| `x` | 横方向的量 |
| `y` | 纵方向的量 |

在游戏编程中，向量经常用来表示位置、方向、速度、移动量，也经常通过加法、减法、标量乘法、长度、正规化、内积、外积来完成移动、追踪、距离判断、方向判断和碰撞判断。

## 1. 常用变量名

| 名称 | 含义 |
|---|---|
| `position` | 某个物体的位置 |
| `basePos` | 基准点 / 参照物的位置 |
| `targetPos` | 目标位置 |
| `objectPos` | 当前要移动的物体位置 |
| `observerPos` | 观察者位置，例如敌人、玩家、摄像机 |
| `forward` | 观察者当前面向的方向 |
| `direction` | 单位方向，长度通常为 `1` |
| `velocity` | 速度向量，表示每秒移动多少 |
| `move` | 本帧移动量，表示这一帧实际移动多少 |
| `deltaTime` | 一帧经过的时间 |
| `speed` | 速度大小，标量 |
| `range` | 判定范围半径 |
| `radius` | 圆的半径 |

程序中常见的二维向量结构体：

```cpp
struct Vector2 {
    float x;
    float y;
};
```

## 2. 二维向量计算的两大类

二维向量计算可以先分成两种情况：

| 类型 | 例子 | 说明 |
|---|---|---|
| 向量和向量的计算 | `a + b`、`a - b`、`a・b`、`a × b` | 两个向量之间进行计算 |
| 向量和数值的计算 | `a * k`、`a / k` | 向量和普通数值进行计算 |

这里的普通数值在数学中叫 `スカラー`，中文叫 `标量`。

例如：

`2`、`0.5`、`speed`、`deltaTime` 都可以看作标量。

下面假设：

`a = (ax, ay)`

`b = (bx, by)`

`k = 普通数值`

## 3. 单个向量：表示基本信息

单个向量不一定需要计算，它本身就可以表示很多信息。

- 表示位置
  - 使用运算：单个向量
  - 公式：`position = (x, y)`
  - 结果类型：向量
  - 含义：表示物体在画面或世界中的位置

- 表示方向
  - 使用运算：单个向量
  - 公式：`direction = (x, y)`
  - 结果类型：向量
  - 含义：表示物体朝哪个方向移动或面向哪里
  - 注意：方向向量通常会使用单位向量，也就是长度为 `1` 的向量

- 表示面向方向
  - 使用运算：单个向量
  - 公式：`forward = (x, y)`
  - 结果类型：向量
  - 含义：表示角色、敌人、摄像机当前朝向哪里

## 4. 向量加法：更新位置

### 4.1 公式

`a + b = (ax + bx, ay + by)`

也就是：

`x` 和 `x` 相加，`y` 和 `y` 相加。

### 4.2 例子

`a = (2, 3)`

`b = (5, 1)`

所以：

`a + b = (2 + 5, 3 + 1) = (7, 4)`

### 4.3 用途

向量加法最常见的用途是：

`位置 + 移动量 = 新位置`

例如：

`position = (100, 200)`

`move = (5, 0)`

那么：

`position + move = (105, 200)`

也就是说，物体原来在 `(100, 200)`，这一帧向右移动 `5`，新位置就变成 `(105, 200)`。

### 4.4 程序理解

```cpp
Vector2 Add(Vector2 a, Vector2 b) {
    Vector2 result;

    result.x = a.x + b.x;
    result.y = a.y + b.y;

    return result;
}
```

## 5. 向量减法：求相对位置 / 方向

### 5.1 公式

`a - b = (ax - bx, ay - by)`

也就是：`x` 和 `x` 相减，`y` 和 `y` 相减。

### 5.2 例子

`a = (10, 8)`

`b = (3, 2)`

所以：

`a - b = (10 - 3, 8 - 2) = (7, 6)`

### 5.3 核心理解

向量减法最重要的用途是：

`targetPos - basePos`

它表示：

`目标相对于基准点的位置向量`

也可以理解为：

`从基准点指向目标的向量`

这里不要只写成“自己”，因为 `basePos` 可以是玩家、敌人、摄像机、子弹、地图原点等任何参照物。

例如：

`basePos = (0, 0)`

`targetPos = (-1, 0)`

那么：

`targetPos - basePos = (-1, 0) - (0, 0) = (-1, 0)`

意思是：目标相对于基准点，在左边 `1` 的方向。

### 5.4 由向量减法派生出的常用公式

向量减法本身只负责得到 `相对位置向量`，后面的单位方向、距离、范围判断、碰撞判断、内积方向判断、外积左右判断，都是在这个差向量基础上继续派生出来的。

- [8. 正規化：由长度和标量除法派生](#8-正規化由长度和标量除法派生)
  - 前提：`toTarget = targetPos - basePos`
  - 派生公式：`direction = normalize(toTarget)`
  - 含义：把相对位置向量变成长度为 `1` 的单位方向。

- [10. 距离公式：由向量减法派生](#10-距离公式由向量减法派生)
  - 前提：`diff = posA - posB`
  - 派生公式：`distance = length(diff)`
  - 含义：先得到两点之间的差向量，再求这个差向量的长度。

- [11. 距离公式的应用：范围判断](#11-距离公式的应用范围判断)
  - 前提：`distance = length(targetPos - basePos)`
  - 派生公式：`length(targetPos - basePos) <= range`
  - 含义：判断目标是否进入以基准点为中心的范围。

- [12. 距离公式的应用：圆形碰撞](#12-距离公式的应用圆形碰撞)
  - 前提：`distance = length(posA - posB)`
  - 派生公式：`length(posA - posB) <= radiusA + radiusB`
  - 含义：判断两个圆心距离是否小于等于半径和。

- [13. 内積 / 点积](#13-内積--点积)
  - 前提：`toTarget = normalize(targetPos - observerPos)`
  - 派生公式：`dot(forward, toTarget)`
  - 含义：判断观察者前方向和目标方向是否接近。

- [18. 外積](#18-外積)
  - 前提：`toTarget = targetPos - observerPos`
  - 派生公式：`cross(forward, toTarget)`
  - 含义：判断目标在观察者的左边还是右边。

简单关系：

`向量减法 → 相对位置向量 → 正规化 / 距离 / 内积判断 / 外积判断`

### 5.5 程序理解

```cpp
Vector2 Subtract(Vector2 a, Vector2 b) {
    Vector2 result;

    result.x = a.x - b.x;
    result.y = a.y - b.y;

    return result;
}
```

## 6. 标量乘法：改变向量长度

### 6.1 公式

`k * a = (k * ax, k * ay)`

也可以写成：

`a * k = (ax * k, ay * k)`

意思是：向量的每个成分都乘上这个数值。

### 6.2 例子

`a = (3, 4)`

`k = 2`

所以：

`2a = (2 * 3, 2 * 4) = (6, 8)`

### 6.3 用途

向量乘以数值，主要用于改变向量长度。

方向不变，长度改变。

游戏中常用于：

`velocity = direction * speed`

也就是：

`速度向量 = 单位方向 × 速度大小`

### 6.4 程序理解

```cpp
Vector2 Multiply(Vector2 v, float k) {
    Vector2 result;

    result.x = v.x * k;
    result.y = v.y * k;

    return result;
}
```

## 7. 长度：由勾股定理得到距离

### 7.1 含义

向量的长度表示这个向量有多长。

数学中常写成：

`|v|`

或者：

`||v||`

两种写法都可以理解为“向量 v 的长度”。

程序里常写成：

`length(v)`

### 7.2 公式

如果：

`v = (x, y)`

那么长度是：

`length(v) = √(x² + y²)`

这其实就是勾股定理。

### 7.3 例子

`v = (3, 4)`

所以：

`length(v) = √(3² + 4²)`

`length(v) = √(9 + 16)`

`length(v) = √25`

`length(v) = 5`

### 7.4 程序理解

```cpp
float Length(Vector2 v) {
    float result;

    result = sqrtf(v.x * v.x + v.y * v.y);

    return result;
}
```

## 8. 正規化：由长度和标量除法派生

`正規化` 不是和 `向量 / 数值` 平级的独立运算，而是 `长度` 和 `标量除法` 组合出来的应用。

关系是：

`向量 / 数值`

- 普通情况：`a / k`
- 正规化：`v / length(v)`

也就是说，`标量除法` 是基础工具，`正規化` 是用这个工具把向量变成单位方向。

### 8.1 标量除法：基础工具

`a / k = (ax / k, ay / k)`

意思是：向量的每个成分都除以同一个数值。

例如：

`a = (6, 8)`

`k = 2`

所以：

`a / 2 = (6 / 2, 8 / 2) = (3, 4)`

这个运算会缩短向量，结果仍然是一个向量。

### 8.2 正規化的含义

`正規化` 指的是把一个向量变成长度为 `1` 的向量，同时保持方向不变。

正规化后的向量叫 `単位ベクトル`，中文叫 `单位向量`。

### 8.3 正規化公式

`normalize(v) = v / length(v)`

也就是：

`单位方向 = 向量 / 向量长度`

这里用到的就是前面的 `向量 / 数值`，只是这个数值不是随便给的 `k`，而是向量自己的长度 `length(v)`。

### 8.4 例子

`v = (3, 4)`

它的长度是：

`length(v) = 5`

所以正规化后：

`normalize(v) = (3 / 5, 4 / 5) = (0.6, 0.8)`

这个 `(0.6, 0.8)` 的长度就是 `1`。

### 8.5 为什么要正规化

如果不正规化，向量本身越长，移动就会越快。

例如：

`directionA = (1, 0)`

`directionB = (10, 0)`

它们方向都向右，但长度不同。

如果直接乘速度或直接加到位置上，`directionB` 会移动得更快。

正规化后：

`normalize(directionA) = (1, 0)`

`normalize(directionB) = (1, 0)`

它们都会变成“纯方向”，这样速度就可以由 `speed` 控制。

### 8.6 注意点

不能除以 `0`。

在正规化时，如果向量长度是 `0`，也不能直接除。

例如：

`v = (0, 0)`

这个向量没有方向，长度也是 `0`，所以不能正规化。

### 8.7 程序理解

```cpp
Vector2 Normalize(Vector2 v) {
    Vector2 result;

    float length = sqrtf(v.x * v.x + v.y * v.y);

    if (length != 0.0f) {
        result.x = v.x / length;
        result.y = v.y / length;
    } else {
        result.x = 0.0f;
        result.y = 0.0f;
    }

    return result;
}
```

## 9. 移动公式：由方向公式派生

移动不是一步完成的，而是由多个基础公式组合出来的。

### 9.1 标准移动流程

```cpp
direction = normalize(targetPos - objectPos);
velocity = direction * speed;
move = velocity * deltaTime;
objectPos = objectPos + move;
```

### 9.2 分级理解

- `targetPos - objectPos`
  - 使用运算：向量减法
  - 得到结果：目标相对于当前物体的位置向量
  - 含义：目标在当前物体看来在哪个方向、离多远

- `normalize(targetPos - objectPos)`
  - 使用运算：正规化
  - 得到结果：长度为 `1` 的单位方向
  - 含义：只保留方向，不保留距离

- `direction * speed`
  - 使用运算：向量 × 数值
  - 得到结果：速度向量 `velocity`
  - 含义：每秒往这个方向移动多少

- `velocity * deltaTime`
  - 使用运算：向量 × 数值
  - 得到结果：本帧移动量 `move`
  - 含义：这一帧实际移动多少

- `objectPos + move`
  - 使用运算：向量加法
  - 得到结果：新的位置
  - 含义：把本帧移动量加到当前位置上

### 9.3 有 deltaTime 的标准写法

```cpp
Vector2 toTarget = Subtract(targetPos, objectPos);

Vector2 direction = Normalize(toTarget);

Vector2 velocity = Multiply(direction, speed);

Vector2 move = Multiply(velocity, deltaTime);

objectPos = Add(objectPos, move);
```

### 9.4 没有 deltaTime 的简单课堂写法

```cpp
position = position + velocity;
```

这种情况下，`velocity` 经常被直接当作“每帧移动量”。

严格来说：

`velocity` 表示速度，也就是每秒移动多少。

`move` 表示本帧移动量，也就是这一帧实际移动多少。

有 `deltaTime` 时应该写成：

`move = velocity * deltaTime`

## 10. 距离公式：由向量减法派生

距离判断不是直接用两个坐标，而是先求差向量，再求长度。

### 10.1 两点差向量

- 使用运算：向量减法
- 公式：`diff = posA - posB`
- 结果类型：向量
- 含义：得到 A 相对于 B 的位置方向

例如：

`posA = (10, 5)`

`posB = (4, 1)`

那么：

`diff = posA - posB = (6, 4)`

这个 `(6, 4)` 表示：A 相对于 B，在右边 `6`、下边 `4`。

### 10.2 两点距离

- 前提公式：`diff = posA - posB`
- 使用运算：向量减法 + 长度
- 公式：`distance = length(posA - posB)`
- 展开公式：`distance = √((posA.x - posB.x)² + (posA.y - posB.y)²)`
- 结果类型：数值
- 含义：得到 A 和 B 之间实际相隔多远

例如：

`diff = (6, 4)`

那么：

`distance = length(diff)`

`distance = √(6² + 4²)`

`distance = √52`

`distance ≈ 7.21`

### 10.3 区别总结

| 写法 | 结果类型 | 含义 |
|---|---|---|
| `posA - posB` | 向量 | A 相对于 B 的位置方向，包含方向和长度信息 |
| `length(posA - posB)` | 数值 | A 和 B 之间的实际距离，只保留长度信息 |

简单记忆：

`减法得到方向向量，length 得到距离数值。`

### 10.4 由距离公式派生出的常用判断

距离公式本身只是得到两个点之间的距离：

`distance = length(posA - posB)`

有了这个距离以后，才可以继续派生出范围判断、圆形碰撞，以及它们的优化版。

- [11. 距离公式的应用：范围判断](#11-距离公式的应用范围判断)
  - 前提公式：`distance = length(targetPos - basePos)`
  - 派生公式：`distance <= range`
  - 合并写法：`length(targetPos - basePos) <= range`
  - 含义：判断目标是否进入以基准点为中心的范围。

- [12. 距离公式的应用：圆形碰撞](#12-距离公式的应用圆形碰撞)
  - 前提公式：`distance = length(posA - posB)`
  - 派生公式：`distance <= radiusA + radiusB`
  - 合并写法：`length(posA - posB) <= radiusA + radiusB`
  - 含义：判断两个圆是否接触或重叠。

- [15. 距离平方：由内积派生](#15-距离平方由内积派生)
  - 前提公式：`diff = posA - posB`
  - 派生公式：`distanceSq = dot(diff, diff)`
  - 含义：不用 `sqrt`，直接得到两点距离的平方。

- [16. 距离平方的应用：范围判断优化版](#16-距离平方的应用范围判断优化版)
  - 前提公式：`distanceSq = dot(diff, diff)`
  - 派生公式：`distanceSq <= range * range`
  - 含义：不用开平方判断目标是否进入范围。

- [17. 距离平方的应用：圆形碰撞优化版](#17-距离平方的应用圆形碰撞优化版)
  - 前提公式：`distanceSq = dot(diff, diff)`
  - 派生公式：`distanceSq <= (radiusA + radiusB) * (radiusA + radiusB)`
  - 含义：不用开平方判断两个圆是否碰撞。

简单关系：

`向量减法 → 差向量 → length 求距离 → 范围判断 / 圆形碰撞`

优化关系：

`向量减法 → 差向量 → dot(diff, diff) 求距离平方 → 范围判断优化 / 圆形碰撞优化`

## 11. 距离公式的应用：范围判断

### 11.1 范围判断公式

- 前提公式：`distance = length(targetPos - basePos)`
- 使用运算：向量减法 + 长度 + 比较
- 公式：`length(targetPos - basePos) <= range`
- 结果类型：bool
- 含义：判断目标是否进入以基准点为中心的范围

### 11.2 分级理解

- `targetPos - basePos`
  - 使用运算：向量减法
  - 得到目标相对于基准点的差向量

- `length(targetPos - basePos)`
  - 使用运算：长度
  - 得到目标和基准点之间的距离

- `<= range`
  - 使用运算：比较
  - 判断距离是否小于等于范围半径

### 11.3 范围判断的常见用途

范围判断公式是：

`length(targetPos - basePos) <= range`

它的本质是：判断目标是否进入以 `basePos` 为中心、半径为 `range` 的圆形范围。

- 攻击范围判断
  - 使用公式：`length(playerPos - enemyPos) <= attackRange`
  - 含义：判断玩家是否进入敌人的攻击范围。
  - 相关基础：[10. 距离公式：由向量减法派生](#10-距离公式由向量减法派生)

- 拾取范围判断
  - 使用公式：`length(itemPos - playerPos) <= pickupRange`
  - 含义：判断道具是否进入玩家的拾取范围。
  - 相关基础：[10. 距离公式：由向量减法派生](#10-距离公式由向量减法派生)

- 视野距离判断
  - 使用公式：`length(targetPos - observerPos) <= viewRange`
  - 含义：先判断目标是否在观察者的视野距离内。
  - 进一步的方向和角度判断看：[13.4 判断目标是否在前方](#134-判断目标是否在前方) 和 [13.5 视野角度判断](#135-视野角度判断)。

- 触发区域判断
  - 使用公式：`length(playerPos - triggerPos) <= triggerRange`
  - 含义：判断玩家是否进入某个触发区域，例如开门、对话、机关启动等。
  - 相关基础：[10. 距离公式：由向量减法派生](#10-距离公式由向量减法派生)

- 优化版范围判断
  - 普通范围判断：`length(targetPos - basePos) <= range`
  - 优化版范围判断：`dot(diff, diff) <= range * range`
  - 详细说明看：[16. 距离平方的应用：范围判断优化版](#16-距离平方的应用范围判断优化版)。

简单关系：

`距离公式 → 范围判断 → 攻击范围 / 拾取范围 / 视野距离 / 触发区域`

如果只需要判断“有没有进入范围”，不需要真实距离数值，程序中更推荐使用距离平方优化版。

## 12. 距离公式的应用：圆形碰撞

### 12.1 圆形碰撞公式

- 前提公式：`distance = length(posA - posB)`
- 使用运算：向量减法 + 长度 + 比较
- 公式：`length(posA - posB) <= radiusA + radiusB`
- 结果类型：bool
- 含义：判断两个圆是否接触或重叠

### 12.2 分级理解

- `posA - posB`
  - 使用运算：向量减法
  - 得到两个圆心之间的差向量

- `length(posA - posB)`
  - 使用运算：长度
  - 得到两个圆心之间的距离

- `radiusA + radiusB`
  - 使用运算：数值加法
  - 得到两个圆半径之和

- `distance <= radiusA + radiusB`
  - 使用运算：比较
  - 如果圆心距离小于等于半径和，说明两个圆碰撞

### 12.3 范围判断和圆形碰撞的关系

- 范围判断
  - `length(targetPos - basePos) <= range`xxx
  - 可以理解为“点进入圆形范围”

- 圆形碰撞
  - `length(posA - posB) <= radiusA + radiusB`
  - 可以理解为“圆和圆之间的距离判断”

所以：

`范围判断和圆形碰撞本质上都是距离比较。`

区别是：

| 类型 | 比较对象 |
|---|---|
| 范围判断 | 距离 `<= range` |
| 圆形碰撞 | 距离 `<= radiusA + radiusB` |

## 13. 内積 / 点积

### 13.1 含义

`内積` 也叫 `点积`。

程序里常写作：

`dot(a, b)`

数学符号常写成：

`a・b`

它的结果不是向量，而是一个普通数值。

### 13.2 公式

如果：

`a = (ax, ay)`

`b = (bx, by)`

那么：

`dot(a, b) = ax * bx + ay * by`

### 13.3 用法一：判断方向关系

当内积用于两个不同方向向量时，例如：

`dot(a, b)`

它常用于判断两个方向之间的关系。

| 内积结果 | 方向关系 |
|---|---|
| `dot(a, b) > 0` | 两个方向大致同向 |
| `dot(a, b) == 0` | 两个方向垂直 |
| `dot(a, b) < 0` | 两个方向大致相反 |

更准确的公式：

`dot(a, b) = ||a||||b||cosθ`

这里的 `θ` 是两个向量之间的夹角。

如果两个向量都已经正规化，也就是长度都是 `1`，那么公式会变成：

`dot(a, b) = cosθ`

这时候内积结果就可以直接用来判断角度关系。

### 13.4 判断目标是否在前方

- 前提公式：`toTarget = normalize(targetPos - observerPos)`
- 使用运算：向量减法 + 正规化 + 内积
- 公式：`dot(forward, toTarget) > 0`
- 结果类型：bool
- 含义：判断目标是否大致在观察者前方

代码思路：

```cpp
Vector2 toTarget = Subtract(targetPos, observerPos);

Vector2 directionToTarget = Normalize(toTarget);

float dotValue = Dot(forward, directionToTarget);

if (dotValue > 0.0f) {
    // 目标大致在前方
}
```

### 13.5 视野角度判断

- 前提公式：`toTarget = normalize(targetPos - observerPos)`
- 使用运算：向量减法 + 正规化 + 内积 + cos + 比较
- 公式：`dot(forward, toTarget) > cos(halfFov)`
- 结果类型：bool
- 含义：判断目标是否在观察者视野角度内

例如：

`halfFov` 是半视野角。

`dot(forward, toTarget)` 越接近 `1`，说明目标越接近正前方。

### 13.6 投影长度

- 使用运算：内积
- 公式：`projectLength = dot(v, unitDir)`
- 结果类型：数值
- 含义：计算向量 `v` 在单位方向 `unitDir` 上的长度

## 14. 内积的另一个用法：求长度平方

内积不只可以判断方向。

当一个向量和自己做内积时：

`dot(v, v)`

它表示：

`dot(v, v) = v.x * v.x + v.y * v.y`

也就是：

`dot(v, v) = length(v)²`

所以它可以用于 [15. 距离平方：由内积派生](#15-距离平方由内积派生)、[16. 距离平方的应用：范围判断优化版](#16-距离平方的应用范围判断优化版)、[17. 距离平方的应用：圆形碰撞优化版](#17-距离平方的应用圆形碰撞优化版)。

### 14.1 求长度平方

- 使用运算：内积
- 公式：`lengthSq(v) = dot(v, v)`
- 结果类型：数值
- 含义：得到向量长度的平方

例如：

`v = (3, 4)`

那么：

`dot(v, v) = 3 * 3 + 4 * 4 = 25`

而：

`length(v) = 5`

所以：

`dot(v, v) = length(v)²`

## 15. 距离平方：由内积派生

### 15.1 两点距离平方

- 前提公式：`diff = posA - posB`
- 使用运算：向量减法 + 内积
- 公式：

```cpp
diff = posA - posB;
distanceSq = dot(diff, diff);
```

- 结果类型：数值
- 含义：得到两点距离的平方，避免使用 `sqrt`

### 15.2 为什么可以这样写

普通距离公式：

`distance = length(diff)`

也就是：

`distance = √(diff.x² + diff.y²)`

如果只做大小比较，可以不用开平方，直接比较平方：

`distance² <= range²`

而：

`distance² = dot(diff, diff)`

所以可以写成：

`dot(diff, diff) <= range²`

---

## 16. 距离平方的应用：范围判断优化版

### 16.1 公式

- 前提公式：`distanceSq = dot(diff, diff)`
- 使用运算：向量减法 + 内积 + 比较
- 公式：

```cpp
diff = targetPos - basePos;
distanceSq = dot(diff, diff);

if (distanceSq <= range * range) {
    // 目标进入范围
}
```

- 结果类型：bool
- 含义：不用 `length` 和 `sqrt`，直接用距离平方判断范围

### 16.2 分级理解

- `diff = targetPos - basePos`
  - 向量减法
  - 得到目标相对于基准点的差向量

- `dot(diff, diff)`
  - 内积
  - 得到差向量的长度平方，也就是距离平方

- `range * range`
  - 数值乘法
  - 得到范围半径的平方

- `distanceSq <= range * range`
  - 比较
  - 判断目标是否进入范围

---

## 17. 距离平方的应用：圆形碰撞优化版

### 17.1 公式

- 前提公式：`distanceSq = dot(diff, diff)`
- 使用运算：向量减法 + 内积 + 比较
- 公式：

```cpp
diff = posA - posB;
distanceSq = dot(diff, diff);
radiusSum = radiusA + radiusB;

if (distanceSq <= radiusSum * radiusSum) {
    // 两个圆碰撞
}
```

- 结果类型：bool
- 含义：不用开平方，也能判断两个圆是否碰撞

### 17.2 分级理解

- `diff = posA - posB`
  - 向量减法
  - 得到两个圆心之间的差向量

- `dot(diff, diff)`
  - 内积
  - 得到两个圆心距离的平方

- `radiusA + radiusB`
  - 数值加法
  - 得到两个圆半径之和

- `radiusSum * radiusSum`
  - 数值乘法
  - 得到半径和的平方

- `distanceSq <= radiusSum * radiusSum`
  - 比较
  - 如果成立，两个圆碰撞

## 18. 外積

### 18.1 含义

`外積` 也是两个向量之间的计算。

在二维中，外积常用来判断左右方向、旋转方向、平行关系、点在边的哪一侧等。

二维外积的结果通常当作一个普通数值来使用。

### 18.2 公式

如果：

`a = (ax, ay)`

`b = (bx, by)`

那么二维外积可以写成：

`cross(a, b) = ax * by - ay * bx`

也就是：

`cross(a, b) = a.x * b.y - a.y * b.x`

### 18.3 例子

`a = (1, 0)`

`b = (0, 1)`

所以：

`cross(a, b) = 1 * 1 - 0 * 0 = 1`

结果大于 `0`，表示 `b` 在 `a` 的某一侧。

具体是左侧还是右侧，要看当前坐标系。

### 18.4 判断目标在左边还是右边

- 前提公式：`toTarget = targetPos - observerPos`
- 使用运算：向量减法 + 外积
- 公式：`cross(forward, toTarget)`
- 结果类型：数值
- 含义：根据外积正负判断目标在观察者的哪一侧

### 18.5 判断旋转方向

- 前提公式：`cross(a, b)`
- 使用运算：外积 + 比较
- 公式：`cross(a, b) > 0 / < 0`
- 结果类型：数值
- 含义：判断从方向 `a` 转向方向 `b` 是顺时针还是逆时针

### 18.6 判断两个方向是否平行

- 前提公式：`cross(a, b)`
- 使用运算：外积 + 比较
- 公式：`cross(a, b) == 0`
- 结果类型：bool
- 含义：外积为 `0` 时，两个方向平行

### 18.7 判断点在边的哪一侧

- 前提公式：`edge = end - start`
- 使用运算：向量减法 + 外积
- 公式：

```cpp
edge = end - start;
toPoint = point - start;
cross(edge, toPoint);
```

- 结果类型：数值
- 含义：判断点在一条边的哪一侧

### 18.8 三角形内部判定

- 前提公式：`cross(edge, point - vertex)`
- 使用运算：外积 + 同号判断
- 公式：

```cpp
cross(edge1, point - vertex1);
cross(edge2, point - vertex2);
cross(edge3, point - vertex3);
```

- 结果类型：bool
- 含义：如果点相对于三条边的外积结果符号一致，通常可以判断点在三角形内部

### 18.9 程序理解

```cpp
float Cross(Vector2 a, Vector2 b) {
    float result;

    result = a.x * b.y - a.y * b.x;

    return result;
}
```

### 18.10 注意点

二维外积结果大于 `0` 或小于 `0` 时，表示两侧不同。

但是到底哪边是左、哪边是右，要看坐标系。

在数学坐标系中，通常 `y` 轴向上。

在屏幕坐标系中，通常 `y` 轴向下。

所以判断左右时，不要只死背正负号，最好结合当前坐标系画图确认。

## 19. 常见计算流程

### 19.1 朝目标移动

目标：让物体朝目标移动。

流程：

- `targetPos - objectPos`
  - 求目标相对于物体的位置向量

- `normalize(targetPos - objectPos)`
  - 得到单位方向

- `direction * speed`
  - 得到速度

- `velocity * deltaTime`
  - 得到本帧移动量

- `objectPos + move`
  - 更新位置

代码思路：

```cpp
Vector2 toTarget = Subtract(targetPos, objectPos);

Vector2 direction = Normalize(toTarget);

Vector2 velocity = Multiply(direction, speed);

Vector2 move = Multiply(velocity, deltaTime);

objectPos = Add(objectPos, move);
```

---

### 19.2 判断距离

目标：判断两个物体之间有多远。

流程：

- `posA - posB`
  - 得到两点差向量

- `length(posA - posB)`
  - 得到两点距离

代码思路：

```cpp
Vector2 diff = Subtract(posA, posB);

float distance = Length(diff);
```

---

### 19.3 判断范围

目标：判断目标是否进入范围。

流程：

- `targetPos - basePos`
  - 得到目标相对于基准点的差向量

- `length(targetPos - basePos)`
  - 得到目标和基准点之间的距离

- `distance <= range`
  - 判断是否进入范围

代码思路：

```cpp
Vector2 diff = Subtract(targetPos, basePos);

float distance = Length(diff);

if (distance <= range) {
    // 目标进入范围
}
```

---

### 19.4 判断圆形碰撞

目标：判断两个圆是否碰撞。

流程：

- `posA - posB`
  - 得到两个圆心之间的差向量

- `length(posA - posB)`
  - 得到两个圆心之间的距离

- `distance <= radiusA + radiusB`
  - 判断是否碰撞

代码思路：

```cpp
Vector2 diff = Subtract(posA, posB);

float distance = Length(diff);

float radiusSum = radiusA + radiusB;

if (distance <= radiusSum) {
    // 两个圆碰撞
}
```

---

### 19.5 判断圆形碰撞优化版

目标：不用开平方判断两个圆是否碰撞。

流程：

- `posA - posB`
  - 得到两个圆心之间的差向量

- `dot(diff, diff)`
  - 得到距离平方

- `(radiusA + radiusB) * (radiusA + radiusB)`
  - 得到半径和平方

- `distanceSq <= radiusSumSq`
  - 判断是否碰撞

代码思路：

```cpp
Vector2 diff = Subtract(posA, posB);

float distanceSq = Dot(diff, diff);

float radiusSum = radiusA + radiusB;

float radiusSumSq = radiusSum * radiusSum;

if (distanceSq <= radiusSumSq) {
    // 两个圆碰撞
}
```

---

### 19.6 判断是否面向目标

目标：判断观察者是否大致看向目标。

流程：

- `targetPos - observerPos`
  - 得到目标相对于观察者的位置向量

- `normalize(targetPos - observerPos)`
  - 得到目标方向

- `dot(forward, toTarget)`
  - 判断观察者前方向和目标方向是否接近

代码思路：

```cpp
Vector2 toTarget = Subtract(targetPos, observerPos);

Vector2 directionToTarget = Normalize(toTarget);

float dotValue = Dot(forward, directionToTarget);

if (dotValue > 0.0f) {
    // 目标大致在观察者前方
}
```

### 19.7 判断目标在左边还是右边

目标：判断目标在观察者左边还是右边。

流程：

- `targetPos - observerPos`
  - 得到目标相对于观察者的位置向量

- `cross(forward, toTarget)`
  - 根据外积正负判断左右

代码思路：

```cpp
Vector2 toTarget = Subtract(targetPos, observerPos);

float crossValue = Cross(forward, toTarget);

if (crossValue > 0.0f) {
    // 目标在某一侧
} else if (crossValue < 0.0f) {
    // 目标在另一侧
}
```

注意：具体正数是左还是右，要看当前坐标系。

## 20. 总整理表

| 计算 | 公式 | 结果 | 主要用途 |
|---|---|---|---|
| 向量加法 | `a + b = (ax + bx, ay + by)` | 向量 | 位置更新、移动 |
| 向量减法 | `a - b = (ax - bx, ay - by)` | 向量 | 求相对位置、求方向 |
| 标量乘法 | `k * a = (kax, kay)` | 向量 | 改变长度、速度计算 |

| 长度 | `length(a) = √(ax² + ay²)` | 数值 | 距离、速度大小 |
| 正规化 | `normalize(a) = a / length(a)` | 向量 | 得到单位方向 |
| 内积 | `dot(a, b) = axbx + ayby` | 数值 | 判断方向关系、夹角 |
| 长度平方 | `dot(a, a)` | 数值 | 距离平方、碰撞优化 |
| 外积 | `cross(a, b) = axby - aybx` | 数值 | 判断左右、旋转方向 |

## 22. 一句话记忆

`向量 + 向量`：常用于位置移动。

`向量 - 向量`：常用于求相对位置和方向。

`向量 × 数值`：常用于控制长度、速度、移动量。

`向量 / 数值`：常用于缩短向量，正规化时会用到。

`length`：表示向量有多长，常用于距离判断。

`正規化`：把向量变成长度为 `1` 的纯方向。

`内積 / 点积`：判断两个方向像不像、夹角大不大；也可以用 `dot(v, v)` 求长度平方。

`外積`：判断左右、旋转方向、点在边的哪一侧。

## 23. 和三维向量的关系

二维向量是：

`v = (x, y)`

三维向量是：

`v = (x, y, z)`

三维向量的大部分计算，就是在二维的基础上多算一个 `z`。

例如二维加法：

`(x1, y1) + (x2, y2) = (x1 + x2, y1 + y2)`

三维加法：

`(x1, y1, z1) + (x2, y2, z2) = (x1 + x2, y1 + y2, z1 + z2)`

二维长度：

`length(v) = √(x² + y²)`

三维长度：

`length(v) = √(x² + y² + z²)`

二维内积：

`dot(a, b) = axbx + ayby`

三维内积：

`dot(a, b) = axbx + ayby + azbz`

所以从二维扩展到三维时，先记住一句话：

`大多数计算只是多处理一个 z。`

但是 `外積` 比较特殊，二维和三维差别较大，三维外积之后需要单独学习。
