# 三次元への拡張

MT2 之前主要学习的是 `2次元`，也就是平面上的数学。进入 MT3 后，学习对象会从平面扩展到 `3次元`，也就是空间中的数学。

`(x, y)` → `(x, y, z)`

`z` 表示空间中的深度方向，也可以理解为“前后方向”。

三维是在二维的基础上增加一个新的坐标成分。以前的很多向量运算仍然可以继续使用，只是计算时要把 `z` 也一起算进去。

---

## 1. 左手座標系

`左手座標系` 是 DirectX 常用的坐标系，所以游戏科课程中也基本按照这个坐标系来讲。

不同图形库、游戏引擎、3D 软件使用的坐标系可能不同。比如：

| 坐标系 | 说明 |
|---|---|
| `左手座標系` | DirectX 常用，本课程主要使用 |
| `右手座標系` | 另一种常见 3D 坐标系 |
| `Z-Up` | 把 `z軸` 作为上方向的坐标系 |

所以学习三维时，要确认当前项目使用的是哪种坐标系。同样的 `z`，在不同系统中可能代表不同方向。

---

## 2. 程序中的三维向量与运算 v = (x, y, z)

二维向量中学过的很多运算，其实不是“二维专用”的，而是向量本身的运算。

所以扩展到三维时，大多数情况下只是多处理一个 `z`。

核心规则是：

`同じ成分同士で計算する`

也就是相同成分之间互相计算：`x` 对 `x`，`y` 对 `y`，`z` 对 `z`。

---

### 2.1 建立向量结构体

首先需要准备一个新的三维向量结构体。

```cpp
struct Vector3 {
    float x, y, z;
};
```

>`Vector2` 仍然会用于 UI、屏幕坐标、2D 图片、鼠标坐标、2D 碰撞等地方。  

---

### 2.2. 加減 (移动)

三维向量的加减就是分别对 `x`、`y`、`z` 进行加减。

公式：

`v1 ± v2 = (x1 ± x2, y1 ± y2, z1 ± z2)`

例如：

`v1 = (1, 2, 3)`

`v2 = (4, 5, 6)`

则：

`v1 + v2 = (5, 7, 9)`

`v1 - v2 = (-3, -3, -3)`

在程序或游戏中，常见用法是：

`新位置 = 当前位置 + 移动量`

例如角色当前位置是 `(10, 0, 5)`，移动量是 `(1, 0, 0)`，那么新位置就是 `(11, 0, 5)`。

---

### 2.3. 乘法 (缩放)

`スカラー` 指的是普通数值，例如 `2`、`0.5`、`3.0f`。

`スカラー倍` 就是用普通数值去乘向量。

公式：

`kv = (kx, ky, kz)`

例如：

`v = (1, 2, 3)`

`k = 2`

则：

`2v = (2, 4, 6)`

在游戏中，常见用法是：

`移动量 = 方向 × 速度`

方向向量表示“往哪里走”，速度决定“走多快”。这就是向量和标量结合使用的典型例子。

---

### 2.4. 内积 (判断方向关系)

三维向量的内积是在二维内积基础上增加 `z` 成分。

公式：

`v1・v2 = x1x2 + y1y2 + z1z2`

例如：

`v1 = (1, 2, 3)`

`v2 = (4, 5, 6)`

则：

`v1・v2 = 1×4 + 2×5 + 3×6 = 32`

内积也可以写成：

`v1・v2 = ||v1||||v2||cosθ`

这个公式说明：内积和两个向量之间的夹角有关。

在游戏中，内积经常用于判断方向关系，例如：

| 判断内容 | 内积的作用 |
|---|---|
| 敌人是否面向玩家 | 判断两个方向是否接近 |
| 玩家是否在敌人视野前方 | 判断夹角是否在一定范围内 |
| 光照强弱 | 判断光线方向和表面方向的关系 |
| 投影计算 | 计算一个向量在另一个方向上的长度 |

简单记忆：

| 内积结果 | 方向关系 |
|---|---|
| 大于 0 | 两个方向大致同向 |
| 等于 0 | 两个方向垂直 |
| 小于 0 | 两个方向大致相反 |

---

### 2.5. 长度

`ノルム` 就是向量的长度，也可以叫 `長さ`。

公式：

`||v|| = √(v・v)`

因为：

`v・v = x² + y² + z²`

所以三维向量长度可以写成：

`||v|| = √(x² + y² + z²)`

例如：

`v = (3, 4, 12)`

则：

`||v|| = √(3² + 4² + 12²)`

`||v|| = √(9 + 16 + 144)`

`||v|| = √169`

`||v|| = 13`

这和二维中的勾股定理很像，只是多了一个 `z²`。

---

### 2.6. 除法 (正規化)

`正規化` 指的是把一个向量变成长度为 `1` 的向量，同时保持方向不变。

公式：

`v / ||v||`

例如：

`v = (3, 0, 4)`

它的长度是：

`||v|| = 5`

所以正规化后是：

`(3 / 5, 0 / 5, 4 / 5) = (0.6, 0, 0.8)`

正规化后的向量长度为 `1`，这种向量也叫 `単位ベクトル`。

在游戏中，方向向量通常要先正规化，再乘以速度。

原因是：如果方向向量本身长度不统一，那么物体移动速度会受到方向向量长度影响，导致速度不稳定。

常见流程：

`目标方向 = 目标位置 - 自己位置`

`单位方向 = 目标方向 / 目标方向的长度`

`移动量 = 单位方向 × 速度`

## 13. 内積の演算規則

内积也有数学运算规则。这里不需要证明，只要知道它可以像普通计算一样按规则处理。

### 13.1 交換法則

`a・b = b・a`

意思是：内积左右交换顺序，结果不变。

---

### 13.2 結合法則

`k(a・b) = (ka)・b = a・(kb)`

这里的 `k` 是 `スカラー`，也就是普通数值。

意思是：标量可以放在不同位置参与计算。

---

### 13.3 分配法則

`a・(b + c) = (a・b) + (a・c)`

意思是：向量和括号里的加法做内积时，可以拆开计算。

---

## 14. 外積は？

课件中提到：`外積` 在二维和三维中差别很大。

三维中常用的外积叫做 `クロス積`，它需要单独定义，所以本节暂时不处理。

现在只需要记住：

`内積` 可以比较自然地从二维扩展到三维。

`外積` 不能简单地把二维公式直接套到三维，需要之后单独学习。

在三维中，外积的结果通常是一个新的向量，并且这个向量会和原来的两个向量垂直。所以它在 3D 图形中非常重要，例如计算法线方向、面朝向、旋转轴等。

---

## 总结

三次元への拡張就是把 MT2 中学过的二维坐标和二维向量，从 `(x, y)` 扩展到 `(x, y, z)`，并在程序中使用 `Vector3` 来处理三维空间中的位置、方向和移动。大多数向量运算只是多计算一个 `z`，但外积在三维中变化较大，需要之后单独学习。


在游戏或图形编程中，三维向量可以用来表示：

| 用途 | 例子 |
|---|---|
| 位置 | 角色在 3D 空间中的位置 |
| 方向 | 角色面向哪里 |
| 移动量 | 每一帧移动多少 |
| 速度 | 物体的运动速度 |
| 距离计算 | 两个物体之间有多远 |
| 视线判断 | 敌人是否看向玩家 |

三维向量是后面学习 3D 图形、摄像机、碰撞、光照、投影的重要基础。
